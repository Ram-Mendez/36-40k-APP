# 11 · Un envío del sur en la cola norte

El muelle norte llama a los envíos de su centro que estén en estado LISTA o URGENTE. La pantalla muestra el 404 y un operario del sur recibe el aviso.

1. **Predice.** `401`, `403` y `406`, una fila por envío.
2. **Reproduce.** Copia [11.sql](11.sql) en la consola y ejecútalo. Anota el primer id, valor o nombre que contradice tu predicción.
3. **Inspecciona.** Ejecuta esta consulta por separado para ver los datos de origen.

   ```sql
   SELECT id, centro, estado FROM sql_lab20.expediciones WHERE id IN (402, 403, 404, 405) ORDER BY id;
   ```
