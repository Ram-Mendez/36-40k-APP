1. **Predice.** La etiqueta del 401 cuesta `8.00`. La del 403, emitida justo el día del cambio, cuesta `10.00`.
2. **Reproduce.** Copia [14.sql](14.sql) en la consola y ejecútalo. Anota el primer id, valor o nombre que contradice tu predicción.
3. **Inspecciona.** Ejecuta esta consulta por separado para ver los datos de origen.

   ```sql
   SELECT desde, euros FROM sql_lab20.tarifas WHERE sku = 'CAJA' ORDER BY desde;
   ```
