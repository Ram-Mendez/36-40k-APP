# 16 · El informe confunde lotes con unidades

Compras quiere saber cuántas unidades recibió de cada producto. Cada fila de `lotes` es una entrega que puede traer varias unidades.

- **Esperado.** De CAJA llegaron dos lotes: uno de `2` unidades y otro de `8`. El informe debe decir `10`.
- **Qué falla.** El informe dice que llegaron `2` unidades de CAJA.
- **Qué ejecutar.** Copia [16.sql](16.sql) a la consola, selecciónalo y pulsa **Ctrl+Enter**.
- **Dónde mirar.** `COUNT(*)` cuenta filas. Abre la tabla `sql_lab20.lotes` y mira qué número trae cada fila en la columna `unidades`.
- **Comprueba tu intento.** Deben salir `CAJA | 10` y `CINTA | 8`.
