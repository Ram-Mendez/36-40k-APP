# 17 · Faltan envíos sin descuento

Facturación quiere listar los envíos que cobraron el precio completo. En estos datos eso puede aparecer de dos formas: `descuento = 0` o `descuento` vacío (`NULL`).

- **Esperado.** Deben salir el `401` y el `404`, que tienen `NULL`, y el `403`, que tiene `0.00`.
- **Qué falla.** El informe solo muestra el `403`.
- **Qué ejecutar.** Copia [17.sql](17.sql) a la consola, selecciónalo y pulsa **Ctrl+Enter**.
- **Dónde mirar.** El `WHERE` compara con cero. `NULL` indica que el valor falta. El `401` no tiene ningún número que se pueda comparar con cero.
- **Comprueba tu intento.** El `402` tiene un descuento de `5.00` y debe seguir fuera.
