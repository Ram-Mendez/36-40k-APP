# 20 · El informe muestra el estante como si fuera su pasillo

El plano necesita mostrar cada estante habilitado y el nombre de su pasillo. En `zonas`, el estante y el pasillo son filas distintas. Por ejemplo, el estante `4` guarda `padre_id = 2`. La fila `2` se llama `Pasillo A`.

- **Esperado.** `Estante A1 | Pasillo A` y `Estante B1 | Pasillo B`.
- **Qué falla.** La columna `pasillo` repite el nombre del estante.
- **Qué ejecutar.** Copia [20.sql](20.sql) a la consola, selecciónalo y pulsa **Ctrl+Enter**.
- **Dónde mirar.** En el `JOIN`, `e` es la fila del estante y `p` es la fila que buscas para el pasillo. Para el estante `4`, compara el id de la fila que encuentra el SQL con el id `2` que debería encontrar.
- **Comprueba tu intento.** Estante B1 debe aparecer con su pasillo aunque ese pasillo esté deshabilitado. El estante deshabilitado B2 debe seguir fuera.
