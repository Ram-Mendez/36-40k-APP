# 22 · Dos ventas desaparecen del total

Facturación quiere sumar lo que se cobra por centro. Si hay descuento, se resta del bruto. Si el descuento vale `NULL`, se cobra el bruto completo.

- **Debe salir.** `NORTE | 199.00` y `SUR | 95.00`.
- **Lo que falla.** El informe devuelve `109.00` para NORTE y `75.00` para SUR.
- **Reproduce.** Copia [22.sql](22.sql) en tu consola, selecciónalo y pulsa **Ctrl+Enter**.
- **Qué mirar.** En la comprobación, mira qué valor produce la resta del `401` antes de que `SUM` empiece a sumar. `SUM` omite los valores `NULL`. Si necesitas un valor por defecto, `COALESCE(NULL, 99)` devuelve `99` y `COALESCE(7, 99)` devuelve `7`.
- **Al probar tu cambio.** El `402` sí tiene 5 euros de descuento y debe aportar 75 euros, no 80.

Ejecuta esta consulta aparte para ver los datos que necesitas.

```sql
SELECT id, centro, bruto, descuento, bruto - descuento AS neto_de_la_fila
FROM sql_lab20.expediciones
ORDER BY id;
```
