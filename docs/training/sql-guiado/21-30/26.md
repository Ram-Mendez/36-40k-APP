# 26 · Una salida de CAJA hace desaparecer a CINTA

Lista los productos de `lotes` que no tienen ninguna salida por WEB. Una salida es un movimiento con unidades negativas.

- **Debe salir.** Solo `CINTA`.
- **Lo que falla.** El listado sale vacío.
- **Reproduce.** Copia [26.sql](26.sql) en tu consola, selecciónalo y pulsa **Ctrl+Enter**.
- **Qué mirar.** `NOT EXISTS` deja pasar una fila cuando la consulta interna no encuentra ninguna. Mira qué fila encuentra ahora la consulta interna aunque estés evaluando CINTA. ¿Qué tendría que tener en común esa fila con el producto de fuera?
- **Al probar tu cambio.** CAJA sí tiene una salida WEB en el `505` y debe quedar fuera. La salida de CINTA en el `504` pertenece a TIENDA.

Ejecuta esta consulta aparte para ver los datos que necesitas.

```sql
SELECT id, sku, canal, unidades
FROM sql_lab20.movimientos
WHERE unidades < 0
ORDER BY id;
```
