# 27 · El mapa imprime el pasillo como almacén

Para cada estante habilitado, muestra su nombre, su pasillo y su almacén. Las tres cosas son filas de `zonas`. `padre_id` apunta al `id` del nivel superior.

- **Debe salir.** `Estante A1 | Pasillo A | Almacen norte` y `Estante B1 | Pasillo B | Almacen norte`.
- **Lo que falla.** Para A1, el informe pone `Pasillo A` también en la columna `almacen`. Para B1 pasa lo mismo con `Pasillo B`.
- **Reproduce.** Copia [27.sql](27.sql) en tu consola, selecciónalo y pulsa **Ctrl+Enter**.
- **Qué mirar.** `e` es el estante, `p` el pasillo y `a` el almacén. Para A1, sigue los ids `4 → 2 → 1` en los datos. Comprueba qué fila usa el segundo `JOIN` para dar el último salto.
- **Al probar tu cambio.** El estante B2 está deshabilitado y debe seguir fuera.

Ejecuta esta consulta aparte para ver los datos que necesitas.

```sql
SELECT id, padre_id, nombre, habilitada
FROM sql_lab20.zonas
WHERE id IN (1, 2, 3, 4, 5, 6)
ORDER BY id;
```
