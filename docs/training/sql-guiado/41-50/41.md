# 41 · Un pedido aparece sin líneas

La aplicación consulta las líneas al abrir un pedido. El método real es [OrderRepository.lines(long id)](../../../../src/main/java/com/acme/operations/order/OrderRepository.java). Lo utiliza `GET /api/v1/orders/{id}`.

El siguiente fragmento Java de práctica contiene un fallo.

```java
long orderId = 101;
jdbc.query(
    "SELECT l.*, p.sku, p.name FROM order_line l"
        + " JOIN product p ON p.id=l.product_id"
        + " WHERE l.product_id=? ORDER BY l.product_id",
    mapper, orderId);
```

Copia [41.sql](41.sql) a la consola y ejecútalo. Usa el valor `101` que Java pasa al `?`. La consulta devuelve **0 filas**, aunque el pedido tiene dos productos.

| order_id | product_id | sku | quantity | unit_price |
| ---: | ---: | --- | ---: | ---: |
| 101 | 1 | GLOVE-100 | 2 | 24.90 |
| 101 | 2 | SCREW-M8 | 2 | 12.75 |

**Pista.** En `order_line`, `order_id` identifica el pedido y `product_id` identifica el producto. Sigue el valor `101` desde `orderId` hasta el `WHERE`.
