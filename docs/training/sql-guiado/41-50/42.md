# 42 · El total de un pedido vacío sale NULL

Cuando se cambia una línea, [OrderRepository.recalculate(long id)](../../../../src/main/java/com/acme/operations/order/OrderRepository.java) calcula el total con `quantity * unit_price`. Si el pedido queda sin líneas, el total debe ser cero.

El siguiente fragmento Java de práctica contiene un fallo.

```java
BigDecimal total = jdbc.queryForObject(
    "SELECT SUM(quantity * unit_price) FROM order_line WHERE order_id=?",
    BigDecimal.class, id);
```

[42.sql](42.sql) ejecuta ese cálculo para dos pedidos. El `101` tiene líneas y el `107` no tiene ninguna. La consulta devuelve `NULL` para el `107`.

| order_id | calculated_total |
| ---: | ---: |
| 101 | 75.30 |
| 107 | 0 |

**Pista.** Comprueba qué devuelve `SUM` cuando el `WHERE` no encuentra filas. Busca una forma de convertir ese resultado a cero.
