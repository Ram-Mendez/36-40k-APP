# 43 · Falta un producto en el inventario

[InventoryRepository.balances(...)](../../../../src/main/java/com/acme/operations/inventory/InventoryRepository.java) obtiene los productos y sus saldos para `GET /api/v1/inventory`. Cada producto debe aparecer aunque todavía no tenga una fila en `inventory_balance`.

El siguiente fragmento Java de práctica contiene un fallo.

```java
String sql = "SELECT p.id, p.sku, COALESCE(i.on_hand, 0), COALESCE(i.reserved, 0)"
    + " FROM product p JOIN inventory_balance i ON i.product_id=p.id";
```

Ejecuta [43.sql](43.sql). Selecciona los productos `1` y `4`, pero solo muestra el `1`.

| id | sku | on_hand | reserved |
| ---: | --- | ---: | ---: |
| 1 | GLOVE-100 | 10 | 4 |
| 4 | TAPE-50 | 0 | 0 |

**Pista.** El producto `4` existe en `product`. En los datos de práctica no tiene fila en `inventory_balance`. Sigue qué hace el `JOIN` en ese caso.
