# 44 · Un informe suma el mismo pedido dos veces

[ReportRepository.sales(...)](../../../../src/main/java/com/acme/operations/report/ReportRepository.java) agrupa los pedidos completados por cliente para `GET /api/v1/reports/sales`. Una fila del informe cuenta pedidos y suma el total de cada pedido.

El siguiente fragmento Java de práctica contiene un fallo.

```java
String sql = """
    SELECT c.id, c.name, COUNT(o.id), SUM(o.total)
    FROM customer c
    JOIN sales_order o ON o.customer_id = c.id
    JOIN order_line l ON l.order_id = o.id
    WHERE o.status = 'COMPLETED'
      AND o.updated_at >= ? AND o.updated_at < ?
    GROUP BY c.id, c.name ORDER BY c.id
    """;
jdbc.query(sql, mapper, Timestamp.from(from), Timestamp.from(to));
```

Ejecuta [44.sql](44.sql). Usa del 1 al 2 de noviembre. Ferretería Central aparece con **3 pedidos y 280.10 €**.

| customer_id | name | orders | total |
| ---: | --- | ---: | ---: |
| 1 | Ferretería Central SL | 2 | 204.80 |
| 2 | Suministros Levante SL | 1 | 49.80 |

**Pista.** El pedido `101` vale 75.30 € y tiene dos filas en `order_line`. Comprueba cuántas veces aparece ese pedido después de unir sus líneas.
