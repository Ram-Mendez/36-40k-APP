# 45 · La consulta busca el pago con los ID cambiados

[BillingRepository.entry(long invoiceId, long entryId)](../../../../src/main/java/com/acme/operations/billing/BillingRepository.java) busca un movimiento dentro de una factura. La petición es `GET /api/v1/billing/invoices/501/entries/1001`.

El siguiente fragmento Java de práctica contiene un fallo.

```java
long invoiceId = 501;
long entryId = 1001;
jdbc.query(
    "SELECT * FROM invoice_entry WHERE invoice_id=? AND id=?",
    ENTRY, entryId, invoiceId);
```

Ejecuta [45.sql](45.sql). Representa los valores que llegan a cada `?` y devuelve **0 filas**. Corrige el SQL e identifica qué cambiarías en los argumentos del fragmento Java.

| id | invoice_id | kind | amount |
| ---: | ---: | --- | ---: |
| 1001 | 501 | PAYMENT | 60.00 |

**Pista.** `invoice_id` es la factura y `id` es el movimiento. Sigue los argumentos de `jdbc.query` en el orden en que aparecen los `?`.
