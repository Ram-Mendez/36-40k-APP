# 46 · El saldo cuenta un pago anulado

[BillingRepository](../../../../src/main/java/com/acme/operations/billing/BillingRepository.java) calcula los pagos y el saldo para `GET /api/v1/billing/invoices/{id}`. La factura `501` tiene un total de **80.30 €** y no tiene créditos por devoluciones de productos.

El bloque de pagos de este fragmento Java de práctica contiene un fallo.

```java
String payments = """
    SELECT invoice_id, SUM(amount) AS paid
    FROM invoice_entry
    GROUP BY invoice_id
    """;
```

Ejecuta [46.sql](46.sql). Sale `paid = 90.00` y `balance = -9.70`.

Las filas de `invoice_entry` son un pago de **60 €**, un `REFUND` de **10 €** y un pago de **20 € anulado**. El reembolso reduce el importe pagado y el pago anulado queda fuera.

| invoice_id | total | paid | balance |
| ---: | ---: | ---: | ---: |
| 501 | 80.30 | 50.00 | 30.30 |

**Pista.** Mira `kind`, `amount` y `reversed_at` para la factura `501`. Revisa qué filas entran en la suma y con qué signo.
