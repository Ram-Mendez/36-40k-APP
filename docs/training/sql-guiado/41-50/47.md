# 47 · La reposición cuenta unidades ya recibidas

[ReplenishmentRepository](../../../../src/main/java/com/acme/operations/replenishment/ReplenishmentRepository.java) calcula las unidades que todavía van a llegar para `GET /api/v1/replenishment/proposals`.

El siguiente fragmento Java de práctica contiene un fallo.

```java
String pending = """
    SELECT l.product_id, SUM(l.quantity) AS incoming
    FROM purchase_order_line l
    JOIN purchase_order o ON o.id = l.purchase_order_id
    WHERE o.status IN ('SUBMITTED', 'PARTIALLY_RECEIVED')
    GROUP BY l.product_id
    """;
```

Ejecuta [47.sql](47.sql). Para los productos `1` y `2` aparecen **16** y **13** unidades por llegar.

| product_id | incoming |
| ---: | ---: |
| 1 | 12 |
| 2 | 10 |

**Pista.** Para el producto `1`, la compra `201` pide 10 y ha recibido 0. La `202` pide 6 y ha recibido 4. `received_quantity` registra lo ya recibido en cada línea.
