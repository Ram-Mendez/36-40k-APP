# 49 · Una página repite un movimiento

[InventoryRepository.movements(Long productId, int page, int size)](../../../../src/main/java/com/acme/operations/inventory/InventoryRepository.java) pagina `GET /api/v1/inventory/movements`. La petición usa `productId=1`, `page=1` y `size=2`. La primera página es la `0`.

El siguiente fragmento Java de práctica contiene un fallo.

```java
jdbc.query(
    "SELECT * FROM stock_movement WHERE product_id=?"
        + " ORDER BY id DESC LIMIT ? OFFSET ?",
    mapper, productId, size, page);
```

Ejecuta [49.sql](49.sql). La página devuelve los ID `2004` y `2003`. El `2004` ya apareció en la página anterior.

| id | product_id | kind | quantity |
| ---: | ---: | --- | ---: |
| 2003 | 1 | RESERVE | 3 |
| 2002 | 1 | ADJUSTMENT | -2 |

**Pista.** Los ID de este producto en orden descendente son `2005, 2004, 2003, 2002, 2001`. La página 0 muestra dos. ¿Cuántas filas debe saltar la página 1?
