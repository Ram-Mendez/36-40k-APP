# 50 · El informe cuenta reservas de otros productos

[ReportRepository.lowStock(...)](../../../../src/main/java/com/acme/operations/report/ReportRepository.java) muestra los productos con poco stock para `GET /api/v1/reports/low-stock`. Por cada producto cuenta cuántos pedidos distintos tienen una reserva de ese producto.

El siguiente fragmento Java de práctica contiene un fallo.

```java
String reservationCount = """
    (SELECT COUNT(DISTINCT r.order_id)
     FROM stock_reservation r)
    """;
```

Ejecuta [50.sql](50.sql), con el umbral de 6 unidades disponibles. Los tres productos muestran **2** pedidos con reserva.

| id | sku | available | orders_reserved |
| ---: | --- | ---: | ---: |
| 4 | TAPE-50 | 0 | 0 |
| 3 | DRILL-18V | 3 | 1 |
| 1 | GLOVE-100 | 6 | 2 |

**Pista.** La tabla `stock_reservation` tiene los pedidos `106` y `109` para el producto `1`, y el pedido `106` para el producto `3`. Sigue qué filas de esa tabla mira la subconsulta cuando la fila exterior es el producto `4`.
