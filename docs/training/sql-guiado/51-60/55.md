# 55 · Una recepción se confunde con otra compra

[ProcurementRepository.previousReceipt(...)](../../../../src/main/java/com/acme/operations/procurement/ProcurementRepository.java) comprueba si ya se procesó una solicitud de recepción para una compra concreta.

Este fragmento Java de práctica contiene un fallo.

```java
jdbc.query(
    "SELECT id, payload_hash FROM purchase_receipt WHERE request_id=?",
    mapper, requestId);
```

Para la compra `202`, el `requestId` es `30000000-0000-0000-0000-000000000001`. [55.sql](55.sql) devuelve dos recepciones porque la compra `204` también usó ese identificador.

| id | purchase_order_id | delivery_reference |
| ---: | ---: | --- |
| 602 | 202 | ALB-202 |

**Pista.** La clave de una recepción anterior se busca con dos datos. El identificador de solicitud está en ambas filas. Compara también el identificador de la compra.
