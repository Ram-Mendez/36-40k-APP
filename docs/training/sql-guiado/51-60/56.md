# 56 · La auditoría mezcla un cliente con un producto

[AuditController.list(...)](../../../../src/main/java/com/acme/operations/common/AuditController.java) permite filtrar `GET /api/v1/audit` por `entityType` y `entityId`. La petición busca `entityType=PRODUCT` y `entityId=1`.

Este fragmento Java de práctica contiene un fallo.

```java
String filter = " WHERE entity_id=?";
jdbc.query("SELECT * FROM audit_event" + filter, mapper, entityId);
```

Ejecuta [56.sql](56.sql). Aparecen dos eventos de producto y un evento del cliente `1`.

| id | entity_type | entity_id | action |
| ---: | --- | --- | --- |
| 3001 | PRODUCT | 1 | PRODUCT_CREATED |
| 3002 | PRODUCT | 1 | STOCK_ADJUSTED |

**Pista.** `entity_id` se guarda como texto. El valor `'1'` puede identificar tanto un cliente como un producto. Mira el otro filtro que envía la petición.
