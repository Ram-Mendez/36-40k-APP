# 57 · Una reserva acepta más unidades de las disponibles

[InventoryService.reserve(...)](../../../../src/main/java/com/acme/operations/inventory/InventoryService.java) comprueba el saldo antes de reservar unidades para un pedido. La petición necesita **7 unidades**.

Este fragmento Java de práctica contiene un fallo.

```java
if (balance.onHand() < quantity) {
    throw new BusinessException(
        HttpStatus.CONFLICT, "INSUFFICIENT_STOCK", "Insufficient available stock");
}
```

[57.sql](57.sql) muestra qué productos pasarían esa comprobación. Para el producto `1` devuelve `true`, aunque tiene 10 unidades físicas y 4 ya reservadas.

| product_id | on_hand | reserved | can_reserve |
| ---: | ---: | ---: | --- |
| 1 | 10 | 4 | false |
| 2 | 8 | 0 | true |

**Pista.** Para el producto `1`, calcula primero `10 - 4`. Compara lo que queda con las 7 unidades solicitadas.
