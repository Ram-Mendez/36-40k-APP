# 59 · Una factura que vence hoy figura vencida

[BillingRepository.receivables(...)](../../../../src/main/java/com/acme/operations/billing/BillingRepository.java) agrupa facturas con saldo pendiente por antigüedad. En esta práctica la fecha de consulta es el **20 de noviembre de 2026**. Una factura que vence ese día sigue en `NOT_DUE`.

Este fragmento Java de práctica contiene un fallo.

```java
String bucket = """
    CASE WHEN age < 0 THEN 'NOT_DUE'
         WHEN age <= 30 THEN '1_30'
         WHEN age <= 60 THEN '31_60'
         WHEN age <= 90 THEN '61_90'
         ELSE 'OVER_90' END
    """;
```

Ejecuta [59.sql](59.sql). La factura `503` tiene `age = 0` y aparece en `1_30`.

| invoice_id | due_date | age | bucket |
| ---: | --- | ---: | --- |
| 501 | 2026-11-30 | -10 | NOT_DUE |
| 502 | 2026-11-01 | 19 | 1_30 |
| 503 | 2026-11-20 | 0 | NOT_DUE |

**Pista.** `age` es la fecha de consulta menos la fecha de vencimiento. Sigue qué `WHEN` acepta el valor `0`.
