# 60 · Una página de dos pedidos muestra solo uno

[OrderRepository.search(...)](../../../../src/main/java/com/acme/operations/order/OrderRepository.java) obtiene una página de pedidos y luego carga sus líneas. Se solicita `page=0`, `size=2` y `sort=createdAt,asc`. El orden es por fecha de creación y después por ID, ambos ascendentes.

Este fragmento Java de práctica contiene un fallo.

```java
jdbc.query(
    "SELECT o.id, l.product_id FROM sales_order o"
        + " JOIN order_line l ON l.order_id=o.id"
        + " ORDER BY o.created_at ASC, o.id ASC, l.product_id ASC LIMIT ? OFFSET ?",
    mapper, size, offset);
```

Ejecuta [60.sql](60.sql). Las dos filas son del pedido `101`. La página debe contener los pedidos `101` y `102` con todas sus líneas.

| order_id | product_id |
| ---: | ---: |
| 101 | 1 |
| 101 | 2 |
| 102 | 3 |

**Pista.** El pedido `101` tiene dos líneas. Comprueba sobre qué filas actúa `LIMIT 2` después del `JOIN`. El método real primero obtiene la página de pedidos y después busca sus líneas.
