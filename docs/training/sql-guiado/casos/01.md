# 01 · Eva desaparece del informe

**Encargo.** Atención al cliente necesita una fila por cliente con el número de pedidos de cualquier estado. Eva está dada de alta y debe figurar con cero.

1. **Predice.** En `sql_lab10.clientes`, Eva tiene `id = 3`. ¿Qué debería mostrar su fila si todavía no ha hecho ningún pedido?
2. **Reproduce.** Abre [01.sql](01.sql) en la consola del lab y ejecútalo. Aparecen Ana, Luis y Leo. Busca a Eva en el resultado.
3. **Localiza dónde se pierde.** Ejecuta estos dos `SELECT` por separado. El primero devuelve a Eva. El segundo utiliza la misma unión que el informe. Fíjate en el número de filas **antes** de contar.

   ```sql
   SELECT c.id, c.nombre
   FROM sql_lab10.clientes AS c
   WHERE c.id = 3;

   SELECT c.id, c.nombre, p.id AS pedido
   FROM sql_lab10.clientes AS c
   JOIN sql_lab10.pedidos AS p ON p.cliente_id = c.id
   WHERE c.id = 3;
   ```

4. **Escribe.** En una copia de la segunda consulta, cambia la unión para conservar la fila de Eva. Cuando veas `pedido = NULL`, lleva ese cambio al informe y vuelve a contar.
5. **Comprueba.** Deben salir cuatro filas en orden. Ana tiene 2 pedidos, Luis 2, Eva 0 y Leo 1.
