# 02 · La lista de clientes para una campaña sale vacía

**Encargo.** Marketing busca clientes que todavía no hayan completado un pedido. Eva nunca ha pedido. Leo tiene un borrador. Ambos cumplen la condición.

1. **Predice.** Ana sí tiene un pedido completado. ¿Debería influir ese pedido en que Leo entre en la campaña?
2. **Reproduce.** Ejecuta [02.sql](02.sql). Devuelve cero filas.
3. **Prueba el interior.** Ejecuta la consulta siguiente. Después cambia `4` por `1`. Estás comprobando, primero para Leo y después para Ana, si existe al menos una compra completada.

   ```sql
   SELECT p.id, p.cliente_id
   FROM sql_lab10.pedidos AS p
   WHERE p.estado = 'COMPLETED' AND p.cliente_id = 4;
   ```

4. **Escribe.** Vuelve a copiar [02.sql](02.sql) y conserva `WHERE NOT EXISTS (`. Dentro de los paréntesis, añade una condición al `WHERE` para comparar `p.cliente_id` con el ID del cliente exterior `c`. En el paso anterior probaste con un ID fijo. Ahora quieres comprobar cada cliente.
5. **Comprueba.** Debes obtener exactamente `3 | Eva` y `4 | Leo`. Ana y Luis tienen al menos una venta completada.

<details><summary>Si te atascas</summary>

Pista 1. El `WHERE` exterior necesita un verdadero o falso. Si escribes `WHERE (SELECT 1 ...)`, PostgreSQL da el error `42804` porque recibe un entero. `WHERE NOT EXISTS (SELECT 1 ...)` da verdadero si la consulta interior devuelve cero filas.

Pista 2. El cliente exterior se llama `c` y tiene un `id`. Dentro, cada pedido `p` guarda a quién pertenece en `cliente_id`.
