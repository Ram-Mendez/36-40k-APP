# 03 · Two single-unit sales disappear from the ranking

**Task.** The warehouse wants products with at least two units sold in total. Only completed orders count. Two sales of one unit of the same product should add up to two.

1. **Predict.** One unit of product `12` sold in order `101` and another in order `104`. Write down the expected total.
2. **Reproduce.** Run [03.sql](03.sql). Product `12` is missing, and product `11` shows only two units.
3. **Inspect the sales before grouping.** Run the query below and add up the units for each product by hand. Then add the condition on `l.unidades` from 03.sql and see which rows disappear.

   ```sql
   SELECT l.producto_id, l.pedido_id, l.unidades
   FROM sql_lab10.lineas AS l
   JOIN sql_lab10.pedidos AS p ON p.id = l.pedido_id
   WHERE p.estado = 'COMPLETED'
   ORDER BY l.producto_id, l.pedido_id;
   ```

4. **Write your change.** Group all completed sales by product. Once the sums match your own, apply the minimum to each group's total. Try a minimum of three as well.
5. **Check.** With a minimum of 2, expect `11 | 3` and `12 | 2`. With a minimum of 3, expect only `11 | 3`. Product `13` belongs to a draft order.

<details><summary>If you get stuck</summary>

Hint 1. `WHERE` decides which rows go into the sum.

Hint 2. `HAVING` filters groups after grouping. Use the group's sum in the condition.

</details>
