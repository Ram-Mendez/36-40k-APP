# 05 · Gloves are missing from the low-stock alert

The warehouse wants products with **4 or fewer available units**. Reserved units are already committed. A product with no stock row has zero units available.

1. **Predict.** There are 10 pairs of gloves and 7 are reserved. Write down how many pairs the shop can sell 3 and whether they should appear in the alert.
2. **Reproduce.** Copy [05.sql](05.sql) into the `lab_20261117` console. Select the query and press **Ctrl+Enter**. The results show Cajas (Boxes) and Bolsas (Bags). Look for the gloves, `id = 11`.
3. **Inspect the row before filtering.** Run the query below separately. Compare the two quantities with the threshold of 4.

   ```sql
   SELECT s.producto_id, s.fisicas, s.reservadas,
          s.fisicas - s.reservadas AS disponibles
   FROM sql_lab10.stock AS s
   WHERE s.producto_id = 11;
   ```

4. **Write your change.** Compare the quantity shown by the `SELECT` in 05.sql with the quantity checked in its `WHERE`. Change the condition in your copy and run it again. If you get stuck, write the comparison for the gloves using numbers first, then replace them with the columns. The `LEFT JOIN` also lets the query check Bolsas.
5. **Check.** With a threshold of 4, expect `11 → 3`, `12 → 4`, and `14 → 0`. Set the threshold to 0 and expect only `14 → 0`. If that fails, look at the two `COALESCE` expressions that handle missing stock.
