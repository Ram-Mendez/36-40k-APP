# INC-014 · El usuario de consulta ve el pedido, pero no puede abrirlo

**Abierta · Prioridad media · Atención al cliente**
**Informante:** Supervisora de atención telefónica.

> Puedo encontrar el pedido en la lista, pero cuando el cliente pregunta por sus líneas e intento abrir el detalle me sale «acceso denegado».

**Muestra de soporte.** Con `operations`, crea un pedido y guarda el ID. Inicia sesión como `readonly`. Con ese mismo token pide el listado de pedidos del cliente y abre `GET /api/v1/orders/{pedido}` con el ID encontrado. El listado devuelve 200 y el detalle devuelve 403. Al consultar ese mismo detalle con `operations`, obtienes 200.

**Criterios de aceptación**

- Con un token de `readonly` vigente, el listado y el detalle devuelven 200 y muestran el mismo pedido.
- Con `readonly`, intentar crear un pedido válido sigue devolviendo 403. Sin sesión, consultar el detalle sigue devolviendo 401.
