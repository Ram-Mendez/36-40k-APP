# BOP-101 — Dirección de entrega acordada por pedido

**Categoría:** desarrollo de funcionalidad. **Prioridad:** media.

**Contexto:** algunos clientes compran para una sucursal distinta de su domicilio habitual. El Product Owner solicita preservar dónde se acordó entregar cada venta.

**Comportamiento esperado:** el borrador admite una dirección de entrega; al crearlo se propone la dirección del cliente. Tras confirmar, editar el cliente no altera la dirección acordada.

**Criterios de aceptación:** nueva migración compatible con pedidos existentes; DTO y OpenAPI explícitos; validación de longitud y campos; edición solo DRAFT; permisos equivalentes a edición de pedido; respuesta y auditoría consultables; tests que cambian dirección de cliente después de confirmar y verifican el histórico. Documentar cómo se tratarán pedidos anteriores sin inventar su dirección histórica.

**Evaluación:** crear cliente y pedido, cambiar ambos domicilios por separado, confirmar y repetir edición. El caso requiere extender el modelo actual, no otro proyecto.
