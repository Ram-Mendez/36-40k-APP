# BOP-107 — Medir el informe comercial con histórico amplio

**Categoría:** consultas SQL y rendimiento. **Prioridad:** media.

**Contexto:** dirección quiere revisar ventas mensuales con varios años de datos. No existe evidencia de rendimiento a esa cardinalidad.

**Comportamiento esperado:** producir una medición reproducible del informe `/reports/sales` antes de decidir si necesita cambios.

**Criterios de aceptación:** generador de datos solo para base aislada, distribución realista por cliente/estado/fecha, EXPLAIN ANALYZE BUFFERS de consulta y count, latencias p50/p95 con condiciones documentadas, resultados idénticos antes/después. Si hay mejora justificada, aportar migración de índice y coste de escritura/espacio; si no, cerrar con evidencia sin añadir índices arbitrarios.

**Evaluación:** comparar un mes reciente frente a un año completo con 100.000 pedidos. Acordar objetivo de latencia sobre el equipo de prueba; no inventar garantías para producción.
