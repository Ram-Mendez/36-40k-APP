# BOP-109 — Ajustes negativos requieren administración

**Categoría:** seguridad y autorizaciones. **Prioridad:** media.

**Contexto:** PO modifica responsabilidades: OPERATIONS podrá registrar recepciones positivas, pero una baja manual de unidades deberá realizarla ADMIN.

**Comportamiento esperado:** ADMIN mantiene ambos signos; OPERATIONS obtiene 403 para quantity negativa; READONLY nunca ajusta. Cancelar pedidos sigue liberando reservas con sus permisos actuales.

**Criterios de aceptación:** autorización también en servicio, contrato/error consistente, tabla de permisos actualizada y tests para roles/signos; rechazo no deja saldo, movimiento ni auditoría de éxito. No deducir permiso desde texto del motivo ni desde un rol enviado en el body.

**Evaluación:** mismo producto y ajuste -1 con cada rol; comprobar tablas. Es un cambio explícito de política sobre comportamiento actual permitido.
